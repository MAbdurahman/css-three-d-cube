# css-three-d-cube

#### <p>A CSS-only 3D cube built with pure HTML and CSS, featuring smooth rotation animations, realistic depth, and transform-based perspective. No JavaScript or external libraries required—ideal for learning CSS 3D transforms, keyframes, and creative UI effects.</p>
